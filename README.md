 Embedded Systems: Arduino Blinking LED Circuit

This is my very first project in **Embedded Systems Design** and **Hardware-Software Co-Design**, built entirely from scratch before starting my first official university lectures. 

  What I Built & Learned
Instead of just copying code blindly, I broke down this architecture detail-by-detail to understand the core physics and computational logic driving it:
* **Hardware Architecture:** Configured an Arduino Uno R3 microchip to route electricity through a custom digital circuit loop.
* **Electrical Safety:** Integrated a resistor to safely regulate current and prevent a fragile LED light from burning out under 5V pressure.
* **Firmware Development:** Wrote execution logic using C++ functions (`setup()` and `loop()`) to directly manipulate silicon transistors at an atomic level.
* **Binary Logic:** Applied the absolute foundations of computing—using `HIGH`!
 (binary 1 / 5 Volts) and `LOW` (binary 0 / 0 Volts) to control a physical device.
